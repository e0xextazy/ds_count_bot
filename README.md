# 📊 Discord-бот подсчёта участников мероприятий

Discord-бот для подсчёта участников в голосовых/сценических каналах во время
мероприятий (МП), с разбивкой по ролям, историей снимков, логированием в
PostgreSQL и экспортом в Google Sheets.

Управление полностью через **админ-панель с кнопками** (`/admin_panel`) —
настройка отслеживаемых войсов, ролей подсчёта и расписания мероприятий
делается прямо из Discord, без правки кода.

> 🟦 Вы в ветке **`js_version`** — реализация на **Node.js / discord.js**.
> Python-версия — в ветке [`main`](../../tree/main).

---

## ✨ Возможности

- **Пересчёт по войсам** — считает всех участников в голосовых и сценических
  каналах с подключёнными людьми, с разбивкой по ролям.
- **Настраиваемые роли подсчёта** (per-guild) — какие роли учитывать, задаётся
  кнопками. При нескольких ролях у участника выигрывает высшая по иерархии сервера.
- **Мероприятия (МП)** — захардкоженный каталог событий со своим временем
  (Диллеры, Цеха, Дроп). Кнопками включаешь/выключаешь, какие МП участвуют
  в запланированном пересчёте.
- **Запланированный пересчёт** — фоновая задача раз в минуту запускает пересчёт
  в момент времени включённого МП (МСК).
- **История** — снимки результатов по дате/времени, просмотр через панель.
- **Логирование в PostgreSQL** — три таблицы:
  - `event_logs` — любое действие с ботом (кнопки, команды, интеракции);
  - `count_logs` — результат каждого пересчёта по каждому войсу;
  - `members_logs` — поимённый состав (ник, дискорд-логин, ID, роль) на момент пересчёта.
- **Экспорт в Google Sheets** — опционально (флаг `EXPORT2SHEET`), пишет
  пересчёты в 10:55 и 18:55 в таблицу.
- **Контроль доступа** — только администраторы Discord + whitelist по user ID.

## 🧩 Структура проекта

| Файл | Назначение |
|---|---|
| `bot.js` | Точка входа: события, команды, регистрация слэш-команд, запуск |
| `config.js` | Константы из env, каталог `EVENTS`, проверка доступа |
| `storage.js` | Состояние (`voice_data.json`): загрузка, миграция, сохранение |
| `client.js` | Экземпляр клиента (intents) + логирование |
| `counting.js` | Подсчёт участников по ролям, расписание МП |
| `recalc.js` | Полный пересчёт + фоновая задача |
| `views.js` | Кнопки и селекты админ-панели + маршрутизация интеракций |
| `db.js` | Логирование в PostgreSQL (`pg`) |
| `sheets.js` | Экспорт в Google Sheets (`googleapis`) |

Граф зависимостей без циклов: `config → storage/client → counting → recalc → views → bot`.

**Стек:** Node.js 18+, [discord.js](https://discord.js.org) v14, `pg`, `googleapis`, `luxon`.

## 🚀 Запуск

### Требования
- Docker + Docker Compose
- Бот в [Discord Developer Portal](https://discord.com/developers/applications)
  с включёнными **Privileged Gateway Intents** (`SERVER MEMBERS` и `MESSAGE CONTENT`).

### Шаги

```bash
# 1. Клонировать и перейти в проект
git clone <repo-url> && cd ds_bot_event_count

# 2. Создать .env из примера и заполнить
cp .env.example .env
nano .env

# 3. (опционально) Положить ключ сервисного аккаунта Google
#    рядом с docker-compose.yml как service_account.json
#    см. GOOGLE_SHEETS_SETUP.md

# 4. Запустить (поднимется бот + PostgreSQL)
docker compose up -d --build

# 5. Логи
docker compose logs -f bot
```

PostgreSQL поднимается тем же compose, таблицы создаются автоматически при старте.

## 🎛️ Команды

| Команда | Тип | Описание |
|---|---|---|
| `/admin_panel` | слэш | Открыть админ-панель с кнопками |

### Кнопки панели
- 📊 **Пересчет всех** — запустить пересчёт вручную
- 🔊 **Добавить войс** / 🔇 **Убрать войс** — отслеживаемые каналы
- 👤 **Добавить роль** / 👤 **Убрать роль** — роли для подсчёта
- 🗓️ **Добавить МП** / 🗓️ **Убрать МП** — включить/выключить мероприятие в расписании
- 📅 **Выбрать дату** / 📈 **История** — просмотр прошлых снимков

## 🗓️ Каталог мероприятий (МП)

Захардкожен в `config.py` (`EVENTS`), время по МСК:

| МП | Время |
|---|---|
| Диллеры | 10:55, 18:55 |
| Цеха | 14:55, 22:55 |
| Дроп | 00:00, 04:00, 08:00, 12:00, 16:00, 20:00 |

По умолчанию включены все. Изменить набор времён — править `EVENTS`.

---

## 🗄️ База данных

Таблицы создаются автоматически при старте (`db.init_db`):

- **`event_logs`** — `event_type, guild_id, channel_id, user_id, user_name, detail, created_at`
- **`count_logs`** — `guild_id, channel_id, channel_name, event_name, trigger, total, roles (jsonb), created_at`
- **`members_logs`** — `guild_id, channel_id, channel_name, event_name, trigger, member_id, member_name, member_login, role_name, created_at`

Если `DATABASE_URL` не задан, логирование в PostgreSQL тихо отключается (бот работает).
