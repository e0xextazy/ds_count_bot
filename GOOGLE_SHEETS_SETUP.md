# Экспорт пересчётов в Google Sheets

Бот при **плановом пересчёте в 10:55 и 18:55** (МСК) пишет результат в Google-таблицу:

- каждая дата — отдельный лист (вкладка) с именем `ДД.ММ`, напр. `17.06`;
- на листе два блока: «Диллеры 10:55» и «Диллеры 18:55»;
- бот заполняет колонку **B** (название роли) и колонку **C** (сколько человек
  этой роли было в войсе на момент пересчёта);
- всё остальное (войс на МП, проценты, формулы) вы вписываете вручную.

Пересчёты в другое время (14:55, 22:55 и ручные) в таблицу **не** пишутся.

## Настройка (один раз)

1. **Google Cloud → сервисный аккаунт**
   - Откройте https://console.cloud.google.com/ , создайте проект (или возьмите свой).
   - APIs & Services → Enable APIs → включите **Google Sheets API** и **Google Drive API**.
   - APIs & Services → Credentials → Create credentials → **Service account**.
   - У созданного аккаунта: Keys → Add key → **JSON** → скачайте файл.
   - Переименуйте его в `service_account.json` и положите рядом с `docker-compose.yml`.

2. **Создайте Google-таблицу** и расшарьте её на email сервисного аккаунта
   (вида `...@...iam.gserviceaccount.com`, он есть в JSON в поле `client_email`)
   с правами **Редактор**.

3. **Возьмите ID таблицы** из её URL:
   `https://docs.google.com/spreadsheets/d/`**`ЭТО_И_ЕСТЬ_ID`**`/edit`
   и впишите в `.env`:
   ```
   GOOGLE_SHEET_ID=ЭТО_И_ЕСТЬ_ID
   EXPORT2SHEET=true
   ```
   Без `EXPORT2SHEET=true` экспорт выключен (по умолчанию `false`).

4. Перезапустите бота: `docker compose up -d --build`.

## Проверка

В лог-канале Discord после 10:55/18:55 появится строка
`📗 Google Sheets обновлён: 17.06 / 10:55: записано ролей — N`.

## Если экспорт не нужен

Поставьте `EXPORT2SHEET=false` (по умолчанию) или оставьте `GOOGLE_SHEET_ID` пустым — бот
просто пропустит экспорт, всё остальное работает как раньше.

> Если запускаете без Google Sheets, уберите из `docker-compose.yml` строку
> монтирования `./service_account.json:/app/service_account.json:ro`, иначе
> Docker создаст на её месте пустую папку.
